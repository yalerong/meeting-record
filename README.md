# 会议录音与纪要

这是一个仅在本机运行的 Windows 小程序：

1. 支持两种会议：**线下会议录麦克风**；**线上会议同时录麦克风和电脑系统声音**。
2. 麦克风使用双路冗余；线上模式另外保留系统声音原轨，并生成一份双方都能听到的 `完整录音.wav`。
3. 结束后使用 faster-whisper `large-v3-turbo` 模型转写中文。
4. 用 sherpa-onnx 做说话人分离，逐字稿标上「说话人1/2/3」。
5. 转写模型释放内存后，使用 Ollama `qwen2.5:7b` 生成带时间戳证据的会议摘要、决定、行动项和待确认问题。
6. Ollama 失败时自动生成基础纪要；任何处理失败都不会删除原始录音。

## 使用

第一次使用先双击 `setup.bat` 安装独立运行环境，以后双击 `start.bat`。

- **线下会议**：选择“线下会议（麦克风）”，说一句话，确认麦克风电平明显跳动。
- **线上会议**：选择“线上会议（麦克风 + 电脑声音）”，先自己说一句话，再播放一段视频或让远端参会者说话，必须确认“麦克风电平”和“系统声电平”都会动。

确认试音后输入会议名称并点击“开始录音”。会议结束后点击“结束并生成纪要”。

会后处理分三个阶段，界面上都有进度：

- 阶段 1 转写：百分比、已处理到录音的第几分钟、已识别多少句、预计还要多久。**逐字稿边转写边写盘**，中途关程序也不会丢已经转好的部分。想中断就点“停止处理”。
- 阶段 2 说话人分离（可关掉）：约占录音时长的 1/10。
- 阶段 3 生成纪要：显示第几步/共几步。

程序崩溃、断电或当时没处理完的录音，用 **“处理已有录音…”** 选择 `原始录音.wav`、`完整录音.wav` 或任意保留下来的原轨即可重新处理，不用重录。

结果保存在 `meetings/<日期时间-会议名称>/`。

线下会议：

- `原始录音.wav` / `备份录音.wav`（两路各存一份）

线上会议：

- `麦克风录音.wav` / `麦克风备份.wav`
- `系统声音.wav`（远端参会者和电脑播放的声音）
- `完整录音.wav`（麦克风与系统声音混合，转写也使用它）

两种模式都会生成：

- `逐字稿.txt`
- `会议纪要.md`
- `录音日志.txt`（两路各自的设备、实际录到的时长、最大音量、自动重连次数）

## 线上会议的系统声音

程序会寻找 Windows 暴露的系统回放录音端点，例如“立体声混音”“电脑扬声器”“Stereo Mix”“What U Hear”或名称包含“Loopback”的输入，并把它们排在“电脑系统声音”下拉框最前面。新版 sounddevice 自带的 PortAudio 会把每个扬声器额外列成一个“xxx [Loopback]”输入，有的话优先选它，不用开“立体声混音”。

其余输入设备也会出现在下拉框里，但带有“非系统回放端点”后缀：只有当你已装了 VB-Cable、VoiceMeeter 之类的虚拟声卡并把会议软件的输出指向它时才应选择这些条目。这个版本不会自行安装虚拟声卡。如果没有任何可选设备，线上模式会禁止开始并明确提示。

所有原轨都按单声道保存（立体声端点会自动合并为单声道）；单个 WAV 文件有 4GB 上限，16kHz 约 37 小时、48kHz 约 12 小时，超过时该路会报错停止，请分段录制。

如果线上模式提示没有系统声音输入：

1. 打开 Windows“更多声音设置” → “录制”。
2. 在设备列表空白处右键，勾选“显示已禁用的设备”。
3. 启用“立体声混音”，回到程序点“刷新”。
4. 如果有多个系统声音候选，选择与线上会议实际使用的扬声器对应的条目。

正式会议前必须播放一段电脑声音，确认系统声电平会动。只有麦克风电平会动，表示只能录到你自己；只有系统声电平会动，表示录不到你自己。

## 拿到音频是第一位的

录音端做了这些事，目标是“无论如何都要留下能听的音频”：

- **双路冗余**：主路用你选的设备，备份路自动挑同一支麦克风的另一条通路（MME ↔ WASAPI）或另一个物理设备，各写各的文件。结束时如果主路是静音而备份路有声音，**自动改用备份录音**去转写。
- **实时电平条**：录到的是静音会立刻显示，连续 15 秒没声音就变红报警并响铃。
- **计时器按实际写入的音频算**，不是墙上时间。流断了计时器就停，一眼看得出来。
- **采集看门狗**：麦克风超过 2 秒不送数据就自动关闭并重开音频流，续写同一个 WAV，重连记录进 `录音日志.txt`。
- **30 秒预录**：点“开始录音”时，会把点击之前最近 30 秒的试音一起写进文件，点晚了也不丢开头。
- **每 5 秒修补 WAV 文件头并强制同步到磁盘**：降低程序强杀或突然断电造成整段 WAV 不可播放的风险。
- **停止后自动校验**：检查每条 WAV 是否可解析、是否有数据、时长是否接近整段录音的墙钟时长；写盘线程未排空、尾部缺失或必要音轨失败时会明确报警并停止自动处理，不能假装保存成功。
- 录音期间阻止系统睡眠和息屏，并每 30 秒重申一次。
- 开始前检查磁盘剩余空间（线下约 230MB/小时；线上因保留三份音轨，可能超过 1GB/小时）。

## 转写与纪要的质量保护

- **录音偏小会自动放大后再转写**（最多 20 倍，原始 WAV 不改），远场会议不至于被识别成空白。
- **过滤 Whisper 的经典中文幻觉**（“请不吝点赞订阅转发打赏”“字幕由…提供”之类）和连续复读，过滤条数写在逐字稿开头。
- `condition_on_previous_text=False`，避免长录音陷入复读循环。
- 说话人标签只用来区分“谁说的”，提示词明确禁止模型据此臆测真实姓名和职务。
- 纪要阶段先检查 Ollama 是否在跑、模型是否存在；不可用时会明确告诉你“这份是简易兜底版”，不再默默降级。

## 会前建议

- 把电脑放在会议桌尽量靠中央的位置，麦克风孔不要被文件或衣物遮挡。
- 接通电源，不要合上笔记本屏幕。
- 开始前一定要看一眼电平条：内置麦克风阵列带噪声抑制，说话人离得远时可能被压成纯静音。
- 会议期间不要关闭程序。即使转写稍后失败，WAV 录音仍会保留。
- 处理阶段全在本机跑，风扇高速运转属于正常现象。

## 最终验收（建议各做一次）

线下会议：

1. 双击 `start.bat`，选择“线下会议（麦克风）”。
2. 对着麦克风说“线下录音验收”，确认麦克风电平会动；录 20–30 秒后结束。
3. 点“打开结果文件夹”，播放 `原始录音.wav`；声音应清楚，时长应与录制时间大致一致。

线上会议：

1. 选择“线上会议（麦克风 + 电脑声音）”，系统声音设备优先选择与当前扬声器对应的“立体声混音”或“电脑扬声器”。
2. 播放一段视频或会议远端声音，同时自己说“线上麦克风验收”；确认两个电平条都会动。
3. 录 30–60 秒后结束，播放 `麦克风录音.wav`、`系统声音.wav` 和 `完整录音.wav`。
4. 前两份原轨应分别包含自己和电脑播放声；`完整录音.wav` 应同时听到两边，且没有明显截断。

两次验收都检查 `录音日志.txt`：不应出现“写入失败”“落盘失败”或“时长异常”。转写模型首次下载和纪要生成可以稍后完成，不影响已经保存并校验过的 WAV 音频。

## 录不到声音时

1. 看 `录音日志.txt` 里两路各自的“最大音量峰值”。低于 60/32768 说明进来的就是静音。
2. Windows 设置 → 系统 → 声音 → 输入：确认麦克风没有静音、音量不是 0。
3. 在程序里换一个麦克风设备（下拉框）再试音，MME 和 WASAPI 两个条目都可以试。
4. 说话人离电脑 1 米以内，或改用外接麦克风/会议全向麦。

## 安装

需要 Windows + Python 3.10 以上。推荐直接双击：

```
setup.bat
```

脚本会在项目目录创建 `.venv` 并安装依赖，不会污染其他 Python 项目。需要命令行手动安装时才使用：

```
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python download_models.py     # 可选：下载说话人分离模型（约 35MB）
```

会议纪要由本机的 [Ollama](https://ollama.com) 生成，需要先拉模型：

```
ollama pull qwen2.5:7b        # 最终合并用
ollama pull qwen2.5:3b        # 可选：长会议的分段摘要用它，省一半时间
```

转写模型 `large-v3-turbo` 首次运行时自动下载（约 1.6GB）。

## 速度参考

在一台无独显的笔记本（纯 CPU）上实测：

| 阶段 | 速度 |
|---|---|
| 转写 large-v3-turbo int8 | 约 2 倍实时 |
| 说话人分离 | 约 12 倍实时 |
| 纪要生成 qwen2.5:7b | 约 1.5 token/s |

也就是说 2 小时的会议，全部处理完大约要 2–3 小时，其中绝大部分花在生成纪要上。录音本身不受影响。

## 隐私

音频、逐字稿、纪要全部只留在本机，程序不向任何外部服务发送数据（Ollama 和转写都是 localhost）。

`meetings/` 已经写进 `.gitignore`，`*.wav` 也一并挡掉。**如果你 fork 或复制这个项目，发布前请再确认一遍 `meetings/` 没有被提交。**
